HandsFree for YouTube は、声だけで YouTube 動画を操作できる Chrome 拡張機能です。

赤ちゃんを抱っこしながら動画を操作したい、料理しながらレシピ動画を見たい、楽器を弾きながら演奏を参考にしたい——
両手がふさがっているあらゆる場面で活躍します。


【音声コマンド一覧】

■ 再生・停止
「再生」「スタート」で再生、「停止」「ストップ」「ポーズ」「一時停止」で一時停止

■ 速度変更
「1倍速」「1.5倍速」「2倍速」など、0.1〜10.0倍の範囲で変更可能
3倍速以上では自動的にミュートになります
「解除」で標準速度（1.0倍速）に戻します

■ 早送り
「10秒スキップ」「30秒スキップ」「1分スキップ」「5分スキップ」など

■ 広告スキップ
「広告スキップ」と発話すると、スキップボタンが表示されるまで最大15秒間待機して自動クリックします
もう一度「広告スキップ」と言うとキャンセルできます

コマンドの末尾に「ください」「します」「だよ」などの語尾が付いていても正しく認識されます。


【使い方】

1. YouTube の動画再生ページを開く
2. 画面右端に表示されるマイクボタンをクリック
3. ブラウザからマイクの許可を求められたら「許可」を選択
4. 音声コマンドを話しかける
5. 使い終わったらマイクボタンをもう一度クリックして停止

マイクボタンは動画再生ページ以外（トップページ・検索結果など）では表示されません。


【注意事項】

対応ブラウザ：Google Chrome（PC版）
対応言語：日本語
音声認識には Chrome 内蔵の Web Speech API を使用します。音声データは開発者には送信されません。
スピーカー音声の誤認識を防ぐため、イヤホン・ヘッドセットの使用を推奨します。
