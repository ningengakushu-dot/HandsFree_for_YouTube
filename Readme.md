# YouTube Voice Control

YouTube ウェブサイト上でビデオの再生、停止、再生速度変更、広告スキップなどを音声で操作するための Google Chrome 拡張機能です。


## 主要機能

- 音声コマンドによるプレーヤー制御（再生、一時停止、速度変更、スキップ、広告スキップ）。
- 3倍速以上の再生時は自動ミュート。（2.9倍速以下でミュート解除）
- 最大10倍速まで対応。

### 音声コマンド一覧

マイクボタンをクリックで音声認識を開始します。

| 操作内容 | コマンド（例） |
| :--- | :--- |
| 再生 | 再生 / スタート |
| 停止 | 停止 / ストップ / ポーズ / 一時停止 |
| 速度変更 | 1倍速 / 2倍速 / 5倍速 |
| 速度解除 | 解除 |
| スキップ | 10秒スキップ / 5分スキップ |
| 広告スキップ | 広告スキップ |
