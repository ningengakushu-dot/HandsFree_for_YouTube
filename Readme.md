# YouTube Voice Control

YouTubeの動画プレーヤーを音声で操作できるGoogle Chrome拡張機能です。
動画の再生・停止、再生速度の変更、広告のスキップなどをハンズフリーで行えます。

## 主要機能

- 音声によるプレーヤー制御: 再生、一時停止、速度変更、指定時間のスキップ、広告スキップに対応。
- 再生速度調整: 最大10倍速まで対応。3倍速以上の設定時は自動的にミュートされ、2.9倍速以下に戻すとミュートが解除されます。
- フローティングマイクボタン: 画面右端に表示されるマイクボタンから、いつでも音声認識のオン・オフを切り替え可能です。
- トースト通知: 認識したコマンドや実行結果を画面上にポップアップ表示します。

## インストール方法

ローカル環境（デベロッパーモード）でのインストール手順です。

1. Google Chromeのアドレスバーに `chrome://extensions/` と入力し、拡張機能の管理画面を開きます。
2. 画面右上の「デベロッパー モード」をオンにします。
3. 画面左上の「パッケージ化されていない拡張機能を読み込む」をクリックします。
4. 本リポジトリの `manifest.json` が含まれているフォルダを選択します。
5. YouTubeのページを開く（または再読み込みする）と、拡張機能が有効になります。

## 使い方

1. YouTubeの動画再生ページ（`/watch`）を開きます。
2. 画面右端に表示されるマイクボタンをクリックし、音声認識を開始します。
   ※初回利用時は、ブラウザからマイクの使用許可を求められるため「許可」を選択してください。
3. 以下の音声コマンドをマイクに向かって発話します。

### 音声コマンド一覧

| 操作内容 | 音声コマンド（例） | 備考 |
| :--- | :--- | :--- |
| 再生 | 「再生」「スタート」 | 一時停止中の動画を再生します。 |
| 停止 | 「停止」「ストップ」「ポーズ」「一時停止」 | 再生中の動画を一時停止します。 |
| 速度変更 | 「1倍速」「1.5倍速」「2倍速」「5倍速」 | 0.1〜10までの数値を指定可能です。 |
| 速度解除 | 「解除」 | 再生速度を標準（1倍速）に戻します。 |
| スキップ | 「10秒スキップ」「5分スキップ」 | 指定した時間だけ動画を早送りします。 |
| 広告スキップ | 「広告スキップ」 | スキップ可能な広告が表示されている場合にクリックします。 |

## 注意事項・推奨環境

本アプリはブラウザの音声認識機能を使用しているため、PCのスピーカーから出力される動画音声をマイクが拾ってしまうと、コマンドの誤認識や意図しない動作を引き起こす場合があります。

これを防ぐため、以下のいずれかの環境での利用を推奨します。

1. ノイズキャンセリングソフトの利用（推奨）
   NVIDIA Broadcastなどのノイズキャンセリングソフトを使用し、Chrome側のマイク入力を仮想マイクに設定することで、スピーカーを利用しながらでも動画音声の回り込みを防ぐことができます。
2. イヤホン・ヘッドセットの使用
   スピーカーを使用せず、イヤホンやヘッドセットを使用することで音声の回り込みを物理的に防ぎます。
3. 指向性の高いマイクの利用
   単一指向性のマイクを使用し、スピーカーの音を直接拾わないように配置を調整してください。

### 動作環境
- 対応ブラウザ: Google Chrome（PC版）
- 対応言語: 日本語 (`ja-JP`) のみ
