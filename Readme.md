# YouTube Voice Control (YouTube 音声操作拡張機能)

YouTube の動画プレーヤーを音声コマンドで直感的に操作できる Google Chrome 拡張機能です。
動画の再生・停止、再生速度の変更、広告のスキップなどの一連の操作を、キーボードやマウスを使わずにハンズフリーで行うことが可能です。

## 主要機能

- **音声によるプレーヤー制御**: 再生、一時停止、再生速度の変更、指定秒数のスキップ、および広告のスキップに対応しています。
- **広範な再生速度調整**: 0.1倍速から最大10倍速まで柔軟に変更可能です（※3倍速以上への変更時は自動的に消音（ミュート）され、2.9倍速以下に戻すと自動的に解除されます）。
- **フローティングマイクボタン**: 画面右端に配置されるマイクアイコンから、即座に音声認識の有効・無効を切り替えられます。
- **トースト通知機能**: 認識された音声コマンドの内容や実行結果を、画面上にリアルタイムでポップアップ表示します。

## インストール方法（デベロッパーモード）

本拡張機能は、以下の手順でローカル環境にインストールして使用します。

1. Google Chrome を起動し、アドレスバーへ `chrome://extensions/` と入力して拡張機能管理画面を開きます。
2. 画面右上の **「デベロッパー モード」** を有効にします。
3. 画面左上の **「パッケージ化されていない拡張機能を読み込む」** をクリックします。
4. 本リポジトリのソースコードが含まれるフォルダ（`manifest.json` が配置されているディレクトリ）を選択します。
5. YouTube の動画ページを開く（またはページを再読み込みする）と、拡張機能が有効になります。

## 使い方

1. YouTube の動画再生ページ（`/watch` で始まるURL）へアクセスします。
2. 画面右端に表示されるマイクボタンをクリックし、音声認識を開始します。
3. ブラウザからマイクの使用許可を求められた場合は「許可」を選択してください。
4. マイクに向かって、以下の音声コマンドを発話します。

### 音声コマンド一覧

| 操作内容 | 音声コマンド（例） | 備考 |
| :--- | :--- | :--- |
| **再生** | 「再生」「スタート」 | 一時停止中の動画を再生します。 |
| **一時停止** | 「停止」「ストップ」「ポーズ」「一時停止」 | 再生中の動画を一時停止します。 |
| **速度変更** | 「1倍速」「1.5倍速」「2倍速」「5倍速」 | 0.1から10.0の範囲で速度を指定できます。 |
| **速度リセット** | 「解除」 | 再生速度を標準（1.0倍速）に戻します。 |
| **スキップ** | 「10秒スキップ」「5分スキップ」 | 発話した時間だけ動画を早送りします。 |
| **広告スキップ** | 「広告スキップ」 | スキップ可能な広告が表示されている場合にクリックを実行します。 |

## 注意事項および動作環境

- **対応ブラウザ**: Google Chrome（PC版）
- **対応言語**: 日本語 (`ja-JP`)
- スピーカーから出力される動画音をマイクが誤認識し、予期しない操作が発生する場合があります。安定した操作のために、**イヤホンやヘッドセットの使用を推奨**します。
