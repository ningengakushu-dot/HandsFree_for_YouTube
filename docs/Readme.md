# HandsFree for YouTube

YouTube の動画プレーヤーを音声コマンドで直感的に操作できる Google Chrome 拡張機能です。
動画の再生・停止、再生速度の変更、早送りなどの一連の操作を、キーボードやマウスを使わずにハンズフリーで行うことが可能です。

## 開発背景

YouTubeでITやプログラミングを学ぶ際、動画を見ながら実際にコードを書いたり、別ウィンドウで作業を並行したり、あるいはリラックスしながらじっくり動画を見たりと、さまざまなスタイルで視聴することが習慣になっていました。

しかしこうした視聴スタイルでは、一時停止・速度変更といった些細な操作のたびにマウスをYouTubeのタブへ移動させなければならず、その都度、手が止まり集中が途切れることがストレスでした。

**「手を止めずに、声だけでYouTubeを操作できれば」** ——そのシンプルなアイデアから、本拡張機能は生まれました。

もともとのきっかけは学習中の不便さでしたが、「両手がふさがった状態でYouTubeを操作したい」というニーズは、学習に限らず日常のあらゆる場面に存在します。料理中にレシピ動画を操作したい、赤ちゃんを抱っこしながら操作したい、楽器を弾きながら演奏動画を参照したい——

本拡張機能は、そういった**あらゆるハンズフリーシーン**に応えるツールです。

## インストール方法

### Chrome Web Store からインストール

Chrome Web Store のページから「Chrome に追加」をクリックするだけでインストールできます。

### ソースコードからインストール（開発者向け）

1. このリポジトリをクローン、またはZIPでダウンロードします。
2. Google Chrome で `chrome://extensions/` を開きます。
3. 画面右上の **「デベロッパー モード」** を有効にします。
4. **「パッケージ化されていない拡張機能を読み込む」** をクリックし、`manifest.json` が含まれるフォルダを選択します。
5. YouTube の動画ページを開くと、拡張機能が有効になります。

## 使い方

1. YouTube の**動画再生ページ**（`youtube.com/watch` から始まるURL）へアクセスします。
2. 画面右端に表示される**マイクボタンをクリック**し、音声認識を開始します。マイクボタンは**ドラッグで任意の位置に移動**でき、位置は次回以降も保持されます。
3. ブラウザからマイクの使用許可を求められた場合は「許可」を選択してください。
4. マイクに向かって音声コマンドを発話します。
5. 使い終わったら、もう一度**マイクボタンをクリック**して音声認識を停止します。

> マイクボタンは動画再生ページ以外（トップページ・検索結果など）では表示されません。

### 音声コマンド一覧

| 操作内容 | 音声コマンド（例） | 備考 |
| :--- | :--- | :--- |
| **再生** | 「再生」「スタート」 | 一時停止中の動画を再生します。 |
| **一時停止** | 「停止」「ストップ」「ポーズ」「一時停止」 | 再生中の動画を一時停止します。 |
| **速度変更** | 「1倍速」「1.5倍速」「2倍速」「5倍速」 | 0.1から10.0の範囲で指定できます。3倍速以上では自動的にミュートになります。 |
| **速度リセット** | 「解除」 | 再生速度を標準（1.0倍速）に戻します。 |
| **〇〇秒スキップ** | 「10秒スキップ」「30秒スキップ」 | 指定した秒数だけ早送りします。 |
| **〇〇分スキップ** | 「1分スキップ」「5分スキップ」 | 指定した分数だけ早送りします。 |
| **広告スキップ** | 「広告スキップ」 | スキップボタンが表示されるまで最大15秒待機し、自動でクリックします。もう一度発話するとキャンセルできます。 |

コマンドの末尾に「ください」「します」「だよ」などの丁寧語・語尾が付いていても正しく認識されます。

## ファイル構成

```
├── manifest.json       # 拡張機能の設定（Manifest V3）
├── content.js          # メインロジック（音声認識・コマンド処理）
├── popup.html          # ポップアップUI
├── popup.js            # ポップアップの状態表示
├── styles.css          # マイクボタン・トースト通知のスタイル
├── icons/              # 拡張機能アイコン（16・48・128px）
└── docs/
    └── PRIVACY.md      # プライバシーポリシー
```

## 技術スタック

- **Manifest V3** — Chrome拡張機能の最新仕様
- **Web Speech API** (`webkitSpeechRecognition`) — Chrome内蔵の音声認識エンジン
- **バニラJS** — フレームワーク・外部ライブラリ不使用

## 注意事項・推奨環境

- **対応ブラウザ**: Google Chrome（PC版）
- **対応言語**: 日本語
- **音声認識エンジン**: Chrome 内蔵の Web Speech API を使用します。音声データは開発者には送信されません。
- スピーカーから出力される動画音をマイクが誤認識し、予期しない操作が発生する場合があります。安定した操作のために、**イヤホンやヘッドセットの使用を推奨**します。
