# Privacy Policy — HandsFree for YouTube

_Last updated: 2026-03-29_

---

## Overview / 概要

HandsFree for YouTube is a Chrome extension that enables voice-controlled playback of YouTube videos.
本拡張機能は、音声コマンドでYouTube動画を操作するChrome拡張機能です。

---

## Data Collection / データ収集

**This extension does not collect, store, or transmit any user data.**

- No personal information is collected.
- No usage data or analytics are gathered.
- No data is sent to any external server operated by the developer.

本拡張機能は、いかなるユーザーデータも収集・保存・送信しません。

---

## Microphone Usage / マイクの使用

This extension uses the browser's built-in **Web Speech API** (`webkitSpeechRecognition`) to recognize voice commands.

- The microphone is activated **only when the user explicitly clicks the mic button**.
- Voice input is processed by **Google's Speech Recognition service**, which is a built-in function of the Chrome browser. The extension developer has no access to this audio data.
- No audio recordings are stored by this extension.

本拡張機能はChrome内蔵のWeb Speech APIを使用します。マイクはユーザーがマイクボタンを押したときのみ有効になります。音声データは拡張機能の開発者には送信されません。

---

## Permissions / 権限

| Permission | Reason |
|---|---|
| `host_permissions: youtube.com` | To inject the voice control interface into YouTube video pages. |

---

## Third-Party Services / 第三者サービス

The only third-party service involved is **Google's Web Speech API**, which is part of the Chrome browser itself. Its use is governed by [Google's Privacy Policy](https://policies.google.com/privacy).
